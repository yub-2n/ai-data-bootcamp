# Olist 셀러 유치·선별 전략 대시보드

> Olist 주문 데이터와 Marketing Funnel 데이터를 결합해 "어떤 셀러를 유치해야 실제로 판매를 시작하는가"를 가설 트리 → 지표 지도 → 원인 분해 → 통계 검증 → 머신러닝 → 결론 → 대시보드의 7단계로 검증한 4인 팀 프로젝트

## 배경·문제정의

- 2017년 상반기에서 2018년 상반기 사이 고객은 크게 늘었지만 셀러는 거의 늘지 않아, 고객:셀러 비율이 **19.8:1 → 39.5:1**로 2.0배 악화됐습니다.
- 그래서 셀러를 더 유치해야 하는데, 계약만 하고 판매를 시작하지 않는 셀러는 회사 매출에 기여하지 않습니다.
- 이 프로젝트는 성공 기준을 **계약이 아니라 활성화(계약 후 90일 안에 첫 주문)**로 두고, 어떤 셀러를 어떤 품목에 얼마나 유치해야 하는지를 회사(마케팅 전략 회의) 관점에서 답합니다.

## 데이터

- Kaggle **Brazilian E-Commerce Public Dataset by Olist**
- Kaggle **Marketing Funnel by Olist** (MQL·계약 데이터)
- 데이터 기준일 2018-08-31
- **데이터 파일은 이 저장소에 포함하지 않았습니다.**

## 분석 방법

| 단계 | 내용 |
|---|---|
| 0. EDA | 데이터셋 구성, 데이터 품질 이슈, 출발점이 된 수요-공급 갭 발견 |
| 1. 가설 트리 | 품질·선별·채널·품목 4개 가지, 검증 가능한 명제로 MECE 분해 |
| 2. 지표 지도 (AARRR) | 셀러 쪽 Acquisition ~ Retention 실측 지표 매핑, 측정 불가 항목은 빈칸으로 명시 |
| 3. 원인 분해 (로직·이슈 트리) | 채택 가설을 사칙연산으로 검산 가능한 유치 목표 수치까지 역산 |
| 4. 통계 검증 | 모든 주장에 유의성과 효과크기를 함께 보고(카이제곱, 비모수 검정, 고정효과 회귀 등) |
| 5. 머신러닝 | 로지스틱 회귀 4개 모델 + 계층 5-fold 교차검증으로 선별 레버를 독립적으로 재확인 |
| 6. 결론·액션 | 회사 이득, 액션 제안, 데이터 한계 |
| 7. 대시보드 | 결론-우선형 스토리보드(상단 KPI → 중단 추이 → 하단 근거), 용어 툴팁·다크 모드 |

## 핵심 결과

- **우선 상담 대상**: 유통(reseller) × 중대형 온라인 셀러. 오프라인 대비 활성화 오즈비 **2.06배 / 1.53배**로 통계 검정과 ML이 같은 방향으로 일치했습니다 (로지스틱 회귀 ROC-AUC 0.62 — 개별 예측 모델은 산출물로 내지 않는다는 것도 결론).
- 이 세그먼트의 활성화율은 **54.9%(151/275)**로 평균 44.1%보다 높아, 같은 계약 98건에서 활성 셀러가 **43명 → 54명(+24.6%)**이 됩니다.
- **품목별 유치 목표**: housewares **+34명**, pet_shop **+9명** (합계 +43명, 계약 73건 환산) — 2017년 하반기 수준의 셀러당 매출 회복 기준.
- **셀러-매출 탄력성 β ≈ 1** (95% CI [0.68, 1.18]): 셀러 수가 늘면 거래액도 거의 같은 비율로 늘어, 셀러 유치는 "파이 나눠먹기"가 아닙니다. 신규 셀러가 기존 셀러 매출을 줄이는 관계도 관측되지 않았습니다.
- 정시 배송 실패 시 평점이 **1.58점** 하락(r = 0.51)해, 신규 셀러 온보딩 때 배송 SLA 교육을 권고했습니다.
- 한계: 인과 미식별, 개별 셀러 예측 불가, 퍼널 데이터 범위 12.3%, 온보딩 이후 데이터 부재.
