# Olist 배송 지연이 리뷰 점수에 미치는 영향

> 브라질 이커머스 Olist 주문 데이터로 "배송이 늦으면 리뷰 점수가 얼마나 떨어지는가", "지연은 어느 배송 단계에서 생기는가"를 통계 검정과 회귀로 확인한 4인 팀 프로젝트 (ML 프로젝트, Insight Digging with ML)

| | 한눈에 보기 |
|---|---|
| **문제** | 배송이 늦으면 리뷰 점수가 얼마나 떨어지고, 지연은 어느 배송 단계에서 생기는가? |
| **결과** | 지연 주문 평균 **2.57점** vs 정시 **4.29점** (Cliff's δ −0.55, large). 지연의 **81%가 운송사 구간**에서 발생 |
| **제안** | 배송 목표를 평균 배송일 단축이 아니라 **정시율(예상배송일 준수)**로 두고, 판매자보다 **운송사 성과 관리**에 집중. 블랙프라이데이 전후 3주는 고위험 구간으로 대비 |
| **내 역할** | 분석 코드 작성·수정, 배송 단계 분해 분석, 발표 자료 수정 (4인 팀) |

## 배경·문제정의

- **핵심 질문**: 배송 지연과 리뷰 점수 사이에 관계가 있는가? (지연될수록 리뷰 점수가 낮아지는가?)
- **보조 질문 1**: 어느 배송 단계(승인·발송준비·운송)에서 지연이 주로 생기는가?
- **보조 질문 2**: 상품 카테고리별로 지연과 리뷰의 관계 강도가 다른가?
- **외부 데이터 보강**: 블랙프라이데이 같은 성수기 캘린더가 배송 지연을 설명하는가?
- **후속 분석**: 이름 붙은 성수기가 아닌 2018년 2~3월에 생긴 지연 급증의 원인은 무엇인가?

## 데이터

- Kaggle **Brazilian E-Commerce Public Dataset by Olist** (9개 CSV 테이블)
  https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- 브라질 공휴일·상업 기념일 날짜(블랙프라이데이, 어머니날, 연인의날, 어린이날, 크리스마스)는 날짜 계산과 공개된 기념일 날짜로 직접 입력했습니다(웹 스크래핑은 하지 않음).
- **데이터 파일은 이 저장소에 포함하지 않았습니다.** 실행 방법은 `실행가이드.md`를 참고하세요.

## 분석 방법

1. 전처리: 리뷰 1:N 처리, 배송 완료 주문 필터링, 구간별 소요일수의 음수(데이터 오류) 처리
2. 지표 정의: 지연 여부, 지연 일수, 구간별 소요일수(승인·발송준비·운송)
3. EDA: 리뷰 점수 분포의 천장효과 확인 → 비모수 방법 선택
4. 핵심 질문: Spearman 상관, Mann-Whitney U 검정, Cliff's delta(효과크기)
5. 교란변수 통제 회귀: OLS, 순서형 로지스틱 회귀(카테고리·가격·할부 통제)
6. 보조 질문: 배송 단계 분해, 카테고리별 차이와 상호작용 검정
7. 외부 데이터 보강: 성수기 캘린더 전후 지연율 비교(카이제곱 검정)
8. Findings → Insights → Recommendations 정리, 한계와 후속 분석 제안

## 핵심 결과

- 지연 주문의 평균 리뷰 점수는 **2.57점**으로 정시 주문(**4.29점**)보다 크게 낮습니다 (Cliff's δ = -0.55, large, p < .001). 지연 *여부*의 효과가 지연 *일수*의 효과(Spearman ρ = -0.18)보다 훨씬 큽니다.
- 지연에 대한 기여는 **운송 구간**(δ = 0.74)이 발송준비(δ = 0.29), 승인(δ = 0.08)보다 압도적으로 큽니다. 지연의 81%가 운송사 구간에서 발생합니다.
- 모든 상위 카테고리에서 지연-리뷰 효과가 크고(δ -0.51 ~ -0.63), 강도 차이는 통계적으로 유의합니다(상호작용 F = 5.67, p < .001). 시계·선물, 뷰티·헬스가 위험지수 상위입니다.
- 성수기 중 **블랙프라이데이만** 지연과 뚜렷하게 연결됩니다. 2017년 블랙프라이데이 전후 3주 지연율이 평시 대비 최대 3.5배(17.9% vs 5.0%)였습니다. 단, 데이터 안에서 관측된 1회 사이클에 근거합니다.
- 2018년 2~3월 지연율이 18.56%(n = 13,455)로 블랙프라이데이 2017(17.94%)급까지 올랐습니다. 지역·판매자·상품 구성·예상배송일 산정 오류는 원인에서 배제했고, 운송 구간에서 전국적으로 생겼다는 것까지 확인했습니다.
- 한계: 관측 데이터라 인과를 확정하지 않으며, 공개 데이터에는 운송사 식별자가 없어 "어느 운송사인가"는 특정할 수 없습니다.
