# insurance-cx 총정리 안내 (2026-11-05)

"약관 난이도와 보험금 분쟁 결과" 프로젝트의 정리된 전체 폴더예요. **팀 안에서만** 주고받아요(원문 결정문이 들어 있어요).
정리 순서: **정유빈 → 팀원B → 팀원C(최종 마무리)**. 앞사람이 끝낸 폴더를 통째로 받아서 이어서 정리해요.

## 2. 이번 정리에서 한 일 (정유빈, 원래 폴더는 그대로 둠)

- **뺀 것**: `Claude outputs/`(압축파일·중복 사본 더미), `인계_C_팀원C_1030/`(옛 인계본), `CLAUDE-1.md`, `agents/*-1.md`(중복), `.DS_Store`, `__pycache__/`, `.claude/settings.local.json`(개인 설정)
- **_보관으로 옮긴 것**: `data/interim/`의 `*_본실행`, `*_사람확인`, `*_수동연결전`, `*_조항점검` 중간 버전 csv
- **골라 넣은 원본 입력**:
  - 골드 30건 사람 대조 양식 → `relabel/사람입력/골드30/`
  - 평가 시트 두 개 → `docs/평가시트_원본/`
  - 폐기한 골드 10건 Claude 초안(투명성용) → `_보관/폐기한_골드10_Claude초안/`
  - 원문 보기 도구 → `_보관/라벨링_도구/`
  - 격리 LLM 실험 설정(CLAUDE.md, 지시.md, 코드북_라벨용.md) → `relabel/격리실험_설정/llm_label_test/`
- 파일 위치는 PROJECT.md에 적힌 경로를 바꾸지 않으려고 **그대로** 뒀어요.
