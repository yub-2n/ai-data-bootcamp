- **처리 건수:** 160건 (보험 권역 160건, 순번 1~160 빠짐·중복 없음, 빈 칸 없음)
- **제외한 것:** 행은 지우지 않았다. 자동차보험은 `is_auto = 1`로 표시만 했다(31건). 조회수·카드뉴스 열은 분석에 쓰지 않아 정리본에서 뺐다(원본에는 있음).
- **불확실한 점:** 자동차 판정 확인 필요 0건(1건은 본문 확인 후 포함으로 판정). 사례 등록일이 2024-07-05 ~ 2026-01-16로 최근 1년 반뿐이다.

수집일: 2026-10-30 · 정리 코드: 이 문서와 같은 작업에서 pandas로 계산(원본 → 정리본, 원본은 수정하지 않음)

## 열 설명

| 열 | 뜻 |
|---|---|
| `list_no` | 보험으로 거른 목록 안의 순번(1~160). 게시판 전체 번호가 아님 |
| `sector` | 권역(모두 "보험") |
| `type_raw` | 사이트 유형 그대로(예: "실손보험(치료비)") |
| `product_group` | 유형의 괄호 앞(예: 실손보험) |
| `coverage` | 유형의 괄호 안(예: 치료비). 괄호가 없으면 빈칸 |
| `title`, `reg_date` | 제목, 등록일 |
| `has_attachment` | 상세내용 첨부가 있으면 1 |
| `site_auto` | 유형이 자동차보험이면 1 |
| `auto_candidate` | 제목에 자동차 관련어(`PROJECT.md` 4-6-2 목록)가 있으면 1 |
| `is_auto` | 1 = 자동차보험(제외), 0 = 포함, 빈칸 = 사람 확인 필요 |
| `needs_review` | 사람이 확인해야 하면 1 |
| `note` | 판정 이유 |

## 사람이 확인할 것

1. ~~**`list_no` 130**~~ — **완료(2026-10-30)**. 본문 확인 결과 중식당 화재에 대한 화재보험 보험금 분쟁이라 자동차보험이 아니다 → `is_auto = 0`.
2. **시기 차이** — 사례는 2024-07 ~ 2026-01에 올라온 것뿐이고, 결정례는 1997~2026년이다. 담보 분포를 나란히 비교할 때 이 차이를 그래프 아래에 적어야 한다.
3. **"보험" 16건** — 유형이 "보험(…)"으로만 되어 있어 상품 종류가 넓다. 담보 분포 그림에서 따로 한 묶음으로 둘지 정해야 한다.
