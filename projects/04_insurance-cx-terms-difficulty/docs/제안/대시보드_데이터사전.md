## 0. 모든 파일 공통

- 인코딩: csv는 utf-8-sig(BOM 있음), 줄바꿈 CRLF. md는 utf-8.
- 빈 칸 = 값 없음(NaN). "수행하지 않음" / "수행하지 못함"은 **문자열**이라 숫자 열에 섞여 있을 수 있다(08). 숫자로 읽을 때 걸러야 한다.
- 비율(`cited_rate`, `share_*`, `ci_*`)은 0~1. 화면에서 %로 바꿀지는 **[팀원C 결정 11/5]** %로, 소수 첫째 자리(CI도 %). 값 자체는 바꾸지 않고 표시만 바꾼다.
- 인용률 CI는 모두 **Wilson 95%**. 오즈비 CI는 05·07·08이 Wald(일반 로지스틱) 또는 프로파일 우도(Firth), 예측 확률 CI는 부트스트랩 백분위(1,000회, 시드 42).
- **난이도 단위**: `difficulty_index`는 지표 4개(문장당 어절, 예외 표현, 참조, 전문용어 비율) z점수의 평균이다(difficulty.csv 261행 기준). 값 0 ≈ 261개 조항 평균. 오즈비는 **분석 157건의 난이도 1 SD(0.5346)당**이다(`통계요약.md` 2장).
- 출처 표기 예: "출처: outputs/stats/05_주모형.csv". 결정문 인용 출처는 "금융감독원 분쟁조정결정례 제○호"(PROJECT.md 6장).
- 화면 전체에 둘 공통 문장(제안): "공개된 금감원 보험 분쟁조정 결정례(자동차보험 제외) 157건 안의 연관성이며 인과가 아니다. 난이도 지수는 '읽기 부담'의 대리 지표다(평가 일치도 카파 0.059)."

## 2. 난이도 프로필 (difficulty_profile.py, 탐색적)

공통 한계(화면에 함께): "난이도 프로필은 결과를 본 뒤 추가한 탐색적 기술 분석이며 인용 여부와 검정하지 않았다. 기준은 현행 표준약관(2026)이다."

- **차원 점수(`dim_*`) 단위**: 0~100 백분위 평균. 표준약관 '전체' 분포에서 그 지표가 몇 백분위인지의 평균. 90 이상 = `high`(표준약관 상위 10%).
- 차원 이름: vocab = 어휘, sentence = 문장 구조, logic = 논리 구조, ref = 참조 구조.

### 11_표준약관기준.csv
- 열: `std_type`(생명보험 / 질병·상해보험 / 실손의료보험 / **전체**), `unit`(조 / 항 / 문장), `n_units`, `usable_n50`(50단위 이상이면 1), `used_as_benchmark`(기준으로 쓴 행 1), 지표 10개 × `_median`, `_p90`(원값).
- 특수 행: **기준으로 쓴 것은 `std_type = 전체` 3행뿐**(used_as_benchmark = 1). 생명·질병상해 조 단위(43, 45)는 50 미만이라 참고용.
- 그림 제안: "표준약관 상위 10% = 문장당 43어절 이상…" 같은 읽는 법 카드(`난이도프로필_요약.md`).
- 한계 문장: "표준약관은 현행본이고 결정례 약관은 1998~2026년 결정의 것이다(분석 포함 기준)."
