# 검수 체크리스트

작성: 팀원C(C) · 2026-10-30
뼈대: `PROJECT.md` 9장(11개 항목). 기준값은 `PROJECT.md` 3장을 그대로 따른다. 이 문서는 기준을 바꾸지 않고, **누가 언제 어떻게 확인하는지**만 붙였다.

## 쓰는 법

- 확인한 사람이 **작성자가 아닌 팀원**이어야 한다(A는 B를, B는 C를, C는 A를).
- 칸마다 `통과` / `미달` / `해당 없음` 중 하나와 **근거**(파일명, 몇 건 중 몇 건)를 적는다.
- 미달이면 고치지 말고 작성자에게 돌려보낸다. 기준을 바꾸고 싶으면 "규칙 변경 제안"으로 팀에 올린다.
- 모르는 것은 "미확인"으로 적는다.
