## 0. 시작 전 (메인 세션)
같은 폴더에서 다른 에이전트(난이도 프로필 등)가 돌고 있으면 끝날 때까지 기다린다.
패키지 설치와 모델 다운로드는 topic-model 에이전트가 `docs/지시/버토픽_실행.md` 0장대로 직접 한다(팀원B 허용). 메인 세션은 따로 설치하지 않는다. 파이썬은 `py -3.10`.

## 1. 분석
topic-model 에이전트에게:
> docs/지시/버토픽_실행.md를 읽고 그대로 실행해. 끝나면 docs/보고/버토픽_실행.md에 보고를 저장하고 멈춰.

## 2. 검수
topic-reviewer 에이전트에게:
> 가장 최근 버토픽 보고와 outputs/stats/17~22, figs/fig_B*를 체크리스트로 검수하고 docs/보고/토픽검수_<회차>.md를 써.

## 3. 반복
- **통과** → 4.
- **수정 필요** → "수정 지시"만 그대로 `docs/지시/버토픽_수정_<n>.md`로 저장하고 topic-model에게 "docs/지시/버토픽_수정_<n>.md를 읽고 해. 끝나면 docs/보고/버토픽_수정_<n>.md에 저장하고 멈춰." → 2로(회차 +1).
- 최대 **3회**. 그래도 아니면 멈추고 남은 항목 보고.
- **사람 확인 필요** → 즉시 멈추고 그대로 보고.
