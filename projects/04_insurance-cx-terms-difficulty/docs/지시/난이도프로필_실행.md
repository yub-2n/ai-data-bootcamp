## 1. 지표 정의 (지금 고정, 결과를 보고 바꾸지 않음)

차원 4개, 지표 10개. ★ = 기존 지표(difficulty_colab.py), ☆ = 새 지표(kiwipiepy 형태소, `difficulty_colab.kiwi(terms)`로 만든 같은 Kiwi 객체 사용).

| 차원 | 지표 | 정의 |
|---|---|---|
| 어휘 | ★ `term_ratio` | 전문용어 명사 ÷ 전체 명사(NNG·NNP) |
| 어휘 | ☆ `noun_chain_max` | 문장 안에서 띄어쓰기와 상관없이 연속된 명사(NNG·NNP·XSN 포함 복합명사)의 최장 길이(형태소 수), 조항 내 최댓값 |
| 문장 구조 | ★ `words_per_sentence` | 문장당 평균 어절 수 |
| 문장 구조 | ☆ `ec_per_sentence` | 문장당 연결어미(EC) 수 (절이 이어지는 정도) |
| 문장 구조 | ☆ `etm_per_sentence` | 문장당 관형형 전성어미(ETM) 수 (절이 명사를 꾸미며 겹치는 정도) |
| 논리 구조 | ★ `exception_count` | 예외·단서 표현 수(expanded 사전) |
| 논리 구조 | ☆ `cond_per_sentence` | 문장당 조건 표현: EC 중 형태 `면`·`으면`·`거든` + 명사 `경우` |
| 논리 구조 | ☆ `neg_count` | 부정 표현 수: 보조용언 `않`, VCN `아니`, 부사 `못`, `없`(VA) |
| 참조 구조 | ★ `ref_count` | 조·항·호·별표 참조 수(each) |
| 참조 구조 | ★ `ref_chain` | 붙어 있는 참조 묶음 수(chain) |

- 새 지표는 모두 **"탐색적, 결과를 본 뒤 추가"** 로 표시한다.
- 형태소 태그 처리에서 정의가 모호한 경우(예: `없`의 품사)는 위 정의대로 하고, 실제로 잡힌 형태 목록 상위 20개를 보고에 적는다. 정의는 바꾸지 않는다.

## 2. 표준약관 기준 분포

1. PDF에서 표준약관 3종(생명보험 / 질병·상해보험 / 실손의료보험 기본형·특별약관) 본문을 뽑는다. 종류별 쪽 범위를 목차와 `TERM_SOURCES`로 정하고 보고에 적는다.
2. **조 단위**(`제N조(제목)` 머리)로 자르고, 같은 조를 **항 단위**(①②…)와 **문장 단위**(Kiwi `split_into_sents`)로도 나눈다.
3. **뺄 것**: 목차, 부칙, 표 셀, **"용어의 정의" 조와 <붙임> 용어 표**(전문용어 사전의 원천이라 넣으면 어휘 차원이 왜곡됨).
4. 모든 단위에 지표 10개를 계산한다. 단위 수를 종류 × 단위별로 적는다. 50단위 미만인 단위는 기준으로 쓰지 않는다.

## 3. 결정례 조항 프로필

1. 대상: `difficulty.csv` 261행. `difficulty_id_map.csv` → `cases.csv`로 `case_key`, `topic`, `issue_type`, `period`, `clause_level`, `clause_text`, `clause_text_article`을 붙이고 `in_analysis`(exclude_reason이 빈 157건)를 표시. 2009-29는 D204만 쓴다(통계 단계 확정).
2. **기존 4개 지표 값은 `difficulty.csv`의 값을 그대로 쓴다.** 새로 계산한 값과 다르면 차이를 보고하고 `difficulty.csv` 값을 쓴다.
3. 새 지표 6개는 `clause_text`로 계산한다.
4. **주 비교 = 조 단위**: `clause_text_article`로 지표 10개를 계산해 표준약관 **조** 분포와 비교한다(단위가 같아서 가장 공정함). `clause_text_article`이 비면 `clause_text`를 쓰고 `bench_note`에 적는다.
5. **보조 비교 = 원래 단위**: `clause_level`이 항·호면 표준약관 항 분포와 비교(호 분포는 만들지 않음).
6. 지표마다 표준약관 분포 안 백분위(0~100, 같은 값은 중간 순위)를 구하고, **차원 점수 = 그 차원 지표 백분위의 평균**.
7. 차원 점수 **90 이상 = `high`** (고정값). 조항마다 `top_dim`(가장 높은 차원, 모두 90 미만이면 "없음").

## 4. 문장 단위 핫스팟 ("어느 문장을 고칠지")

1. 분석 포함 157건의 `clause_text`를 Kiwi로 문장 분리한다.
2. 문장마다 문장 수준 지표(words, ec, etm, cond, neg, exception, ref, noun_chain, term_ratio)를 계산해 **표준약관 문장 분포** 안 백분위를 구한다.
3. 조항마다 차원 점수 평균이 가장 높은 문장을 `hotspot`으로 고르고, 그 문장의 가장 높은 차원을 `hotspot_dim`으로 적는다.
4. 출력 문장은 약관 문구만이다. 문장에 질병명·개인 정보처럼 보이는 말이 있으면 `[가림]`으로 바꾸고 보고에 건수를 적는다.

## 5. 요약과 기준점

- **주제별**(157건, `10_조항주제.csv` topic): 건수, 인용률(10번 값 그대로), 차원 점수 중앙값 4개, 차원별 `high` 비율, 가장 많은 `top_dim`. 5건 미만 주제는 건수만.
- **쟁점 유형별·시기별**: 같은 표.
- **표준약관 기준표**: 종류·단위별 지표 10개의 중앙값과 90 백분위 원값. 보험사 담당자가 "표준약관 상위 10% = 문장당 ○어절, 문장당 조건 ○개"로 읽을 수 있게.
- **차원 간 관계**: 157건 조 단위 차원 점수끼리 스피어만 상관.
- **사람 평가와의 관계(타당성, 탐색적)**: `평가점수.csv`(평가자 2명) → `eval_map.csv`(eval_id↔diff_id)로 24개 조항에 붙여, **두 평가자 평균 점수**와 차원 점수 4개·지표 10개의 스피어만 상관과 부트스트랩 95% CI(1,000회, 시드 42). 평가 일치도가 낮다(카파 0.059)는 점을 같은 표에 적는다. 열 이름이 깨져 보이면 인코딩(cp949/utf-8-sig)을 확인하고 원래 이름을 보고에 적는다.

## 6. 고쳐 쓰기 시연 (규칙으로 뽑음, 사람은 뜻 확인만)

1. **대상 고르기(고정 규칙)**: 주제별 표에서 건수 10건 이상인 주제 중 `건수 × 인용률`이 가장 큰 2개 주제. 각 주제에서 조 단위 차원 점수 평균이 가장 높은 조항 3개씩, 모두 6개. 같으면 diff_id 순.
2. 조항마다 hotspot 문장을 포함한 원문을 **쉬운 우리말로 고쳐 쓴다.** 지킬 것:
   - 보장·면책 조건, 예외, 숫자, 기간, 대상은 **하나도 빼거나 더하지 않는다**
   - 긴 문장은 나누고, 겹친 예외는 목록으로 풀고, 전문용어는 처음 나올 때 괄호로 풀이
   - 법적 효과가 달라질 수 있는 말은 원문 표현을 유지
3. 고친 문장에 지표 10개를 다시 계산해 표준약관 대비 백분위 **전후 비교**를 만든다.
4. 사람 확인 시트 `docs/보고/고쳐쓰기_뜻확인.csv`: rewrite_id, 원문, 고친 문장, 질문("뜻이 같은가?"), 답(예/아니오/일부 다름), 메모. **사람이 '예'라고 하기 전에는 보고서에 "검토 전 시연"으로만 쓴다.**
5. 고쳐 쓴 모델 이름과 지시 문구를 보고에 적는다. 법률 자문이 아니라 가독성 시연이라는 문장을 붙인다.
