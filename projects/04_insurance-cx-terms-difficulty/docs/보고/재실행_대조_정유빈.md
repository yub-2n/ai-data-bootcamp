# 재실행 대조 보고 (정유빈, 2026-11-04)

PROJECT.md 8장 "stats 후: 코드 재실행과 결과 대조"(담당 정유빈). 팀원B 쪽 결과(`찐최종.zip`, stats 수정 5까지 반영)를 **다른 컴퓨터**(리눅스 클라우드 작업 공간, Claude)에서 처음부터 다시 돌려 `outputs/stats/재실행_대조/manifest.csv`(28개)와 비교했다.

## 환경

- Python 3.10.20(리눅스). 팀원B: Python 3.10.11(Windows).
- 패키지는 `requirements.txt` 고정 버전 그대로(numpy 1.26.4, pandas 2.3.3, scipy 1.15.3, statsmodels 0.15.0, scikit-learn 1.7.2, firthlogist 0.5.0, kiwipiepy 0.24.1, pdfplumber 0.11.10, matplotlib 3.10.9, bertopic 0.17.4, sentence-transformers 6.2.0, torch 2.14.1, umap-learn 0.5.12, hdbscan 0.8.44).
- 고정되지 않은 의존 패키지(이 환경 값): numba 0.68.1, llvmlite 0.50.0, pynndescent 0.7.0.
- 입력 파일(`cases.csv`, `difficulty_id_map.csv`, `difficulty.csv`, `issue_type_r2.csv`)은 정유빈 원본과 md5가 같음을 먼저 확인했다.

## 결과

### 1. analysis.py, difficulty_profile.py → 21개 파일 모두 같음

- 01~10, 10_조항주제_기준선, pred_curve, 통계요약.md, 11~16, 13b, 난이도프로필_요약.md.
- `check.py`는 21개 모두 "다름"으로 표시했다. 원인은 줄바꿈이다(Windows CRLF / 리눅스 LF). 줄바꿈을 맞춰 다시 비교하면 **21개 모두 한 글자도 다르지 않다.**
- 결론: 주 결과(오즈비 0.770 [0.524, 1.130]), 민감도, R2(0.803 [0.550, 1.173]), 난이도 프로필은 다른 컴퓨터에서도 같게 재현된다.

### 2. topic.py(BERTopic) → 세부가 다름

같은 임베딩 캐시(`topic_cache/`)와 시드 42~46으로 돌렸다. 임베딩을 새로 계산하지는 않았다.

| 파일 | 결과 |
|---|---|
| 21_면책단서.csv | 같음 |
| 17, 18, 19, 20, 22 | 다름 |

- **토픽 묶음은 거의 같다**: 팀원B 결과와의 ARI는 안건명 0.935, 조항 문구 0.937이다.
- **토픽 번호가 바뀐다**: 예를 들어 안건명 토픽은 팀원B 4 → 이 실행 6, 5 → 4, 6 → 5다. 토픽 이름은 번호에 붙어 있어 다른 환경에서 다시 돌리면 이름과 내용이 어긋난다(22_토픽인용률의 label이 맞지 않게 됨).
- **안정성(시드 5개 쌍별 ARI)이 환경마다 다르다**:

| | 팀원B(Windows) | 이 실행(리눅스) |
|---|---|---|
| 안건명 평균 (최소) | 0.572 (0.057) | 0.867 (0.831) |
| 조항 문구 평균 (최소) | 0.788 (0.697) | 0.656 (0.455) |

  두 환경 모두 기준(평균 0.5 이상)은 통과한다. 다만 팀원B 쪽의 "seed 43만 구조가 크게 다름"은 이 실행에서 나오지 않았고, 이 실행에서는 조항 문구가 더 흔들렸다.
- scikit-learn을 1.9.1로 돌린 실행과 1.7.2로 돌린 실행이 같았다. 그래서 차이는 scikit-learn 탓이 아니고, 운영체제나 UMAP 계산(numba 등 고정되지 않은 패키지) 차이로 본다.
- **추가 확인(2026-11-05)**: 팀원B 쪽 numba 0.68.1, llvmlite 0.50.0, pynndescent 0.7.0으로 이 실행과 **버전이 모두 같다.** 그래서 차이는 패키지 버전이 아니라 **운영체제(Windows / 리눅스) 차이**로 본다. 세 패키지는 requirements.txt에 고정했지만, 운영체제가 다르면 세부가 달라질 수 있으므로 한계 문장은 그대로 둔다.
