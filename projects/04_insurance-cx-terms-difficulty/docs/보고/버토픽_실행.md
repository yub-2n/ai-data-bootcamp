# BERTopic 실행 보고 (지시: docs/지시/버토픽_실행.md)

## 4줄 요약
- 한 일: 안건명(주)과 조항 문구(보조)에 BERTopic을 지시 설정 그대로 돌리고, 규칙 주제·issue_type과 교차표·ARI·NMI, 면책 단서표, 토픽별 인용률(기술통계)을 만들었다. 출력 17~22 csv, 그림 B1~B4, `토픽_요약.md`, `topic.py`.
- 처리 건수: 안건명 346건(이 중 분석 포함 157건), 조항 문구 157건.
