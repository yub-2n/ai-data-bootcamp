- 용도: 서울 ASOS 108이 종로구 송월동에 있어, 강남 호우 사건을 AWS 400으로 다시 잡는 민감도 확인(`src/aws_check.py`, `docs/aws_sensitivity.md`, 유빈 쪽만 있음).

- 한계: AWS와 ASOS는 장비·관리 체계가 다름. 두 지점 결과 차이는 보험 설계의 기준 위험 사례로 씀.
