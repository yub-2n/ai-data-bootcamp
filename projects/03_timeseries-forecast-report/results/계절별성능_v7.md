# v7 계절별 예측 성능 (평가 날짜 기준, FVA 1행 대 7행, 관리소 나눔)

계절은 평가 날짜의 월로 나눴다(봄 3~5월, 여름 6~8월, 가을 9~11월, 겨울 12~2월). 날씨·월·계절 공변량은 모형에 넣지 않았다. **계절별 차이는 그 시기의 행사, 공휴일, 휴관, 학습 이력 길이와 섞여 있으므로 날씨 공변량의 부재 때문이라고 단정하지 않는다.** 정기 격자와 명절 원점은 합치지 않고 따로 낸다.

표본 구성 주의: 평가 구간은 2024-07-02~2025-12-29이라 봄(3~5월)은 2025년 하나뿐이고, 겨울은 2024-12, 2025-01~02, 2025-12의 서로 다른 구간이다. 초기 원점(2024년 하반기)은 모형이 본 학습 이력이 18개월 안팎으로 짧다.
