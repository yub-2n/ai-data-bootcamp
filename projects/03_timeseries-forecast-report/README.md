# 궁·능 일별 관람객 예측과 인력 배치 (시계열 분석보고서)

> 궁·능 23개소의 일별 관람객을 시계열 기초모델 Chronos-2로 예측하고, 무료개방일·명절·휴관일·특별행사 같은 "미리 알 수 있는 운영 정보"를 하나씩 더할 때 예측 정확도와 인력 배치 비용이 얼마나 줄어드는지(FVA)를 백테스트로 검증한 4인 팀 프로젝트

| | 한눈에 보기 |
|---|---|
| **문제** | 궁·능 23개소의 일별 관람객을 미리 예측해, 근무 인원이 모자라거나 남는 비용을 줄일 수 있을까? |
| **결과** | 기존 방식(직전 7일 평균) 대비 Chronos-2 + 운영 정보로 인력 배치 비용 **−42.8%** (19.85억 → 11.35억, 95% 구간 [−49.2, −36.1]), 명절 구간은 **−68.9%** |
| **제안** | 공휴일·명절·정기 무료개방일 일정을 예측에 넣어 근무표를 짠다. 특별행사 효과는 추정 폭이 넓어 추가 검증 후 반영 |
| **내 역할** | 데이터 전처리, 베이스라인·Chronos-2 백테스트 모델링, FVA·부트스트랩 분석 (4인 팀) |

## 배경·문제정의

- 궁·능은 날짜에 따라 관람객 수 변동이 크고(명절, 무료개방일, 특별행사), 근무 인원이 모자라거나 남으면 비용이 생깁니다.
- 23개소의 하루 전체 관람객 수를 예측하고, 예측값을 필요 근무 인원으로 환산합니다.
- 기존 방식(직전 7일 평균)과 시계열 AI 모델을 비교하고, 정보를 하나씩 더할 때의 가치(FVA, Forecast Value Added)를 측정합니다.
- 정확도(WAPE)뿐 아니라 인력 부족·초과 비용까지 같이 봅니다.
  - 비용 가정: 관람객 2,000명당 1명, 모자란 1명·일 60만 원, 남는 1명·일 15만 원, 서비스 수준 q80. 비용은 가상 손실이며 실제 인건비가 아닙니다.
- 근무표를 짜는 시점에 그 정보를 알 수 있었는지(공지 시점)를 구분합니다(확정 시점 A·B).

## 데이터

- 국가유산청 궁능유적본부 「4대궁 관람객 수 현황」「조선왕릉 관람객 수 현황」 (공공데이터포털, 공공누리 제1유형)
- 날씨(NASA POWER), 한국 공휴일 달력
- 팀에서 직접 정리한 무료개방일·특별행사 공변량 파일(공지 날짜 포함)
- **데이터 파일(parquet·csv)은 이 저장소에 포함하지 않았습니다.**

## 분석 방법

- 시계열 9개: 궁 4곳 + 종묘 + 왕릉 관리소 4곳. 관리소 예측값은 최근 개소 비중으로 개소에 배분
- 베이스라인 3개: 나이브, 계절 나이브, 직전 7일 평균 → 비용이 가장 낮은 직전 7일 평균을 기준선으로 사용
- 모델: **Chronos-2 제로샷**(가중치 학습 없음, Colab GPU 실행)
- FVA 7행: 직전 7일 평균 → + 서비스수준 보정 → Chronos-2 → + 요일·휴관 → + 공휴일·명절 → + 정기 무료개방일 → + 특별행사
- 백테스트: 정기 원점 78개(2024-07-02 ~ 2025-12-23, 7일 간격) + 명절 원점 4개
- 구간 추정: 원점·블록 부트스트랩 5,000회
- 최종 산출물: 2026-01-01 ~ 07 개소별 근무 인원 권고표

## 핵심 결과 (정기 78개 원점, 확정 시점 A)

| 행 | 구성 | WAPE | 비용(억) | 1행 대비 |
|---|---|---:|---:|---:|
| 1 | 직전 7일 평균 | 41.3% | 19.85 | 기준 |
| 3 | Chronos-2 | 31.5% | 14.09 | -29.0% |
| 5 | + 공휴일·명절 | 30.4% | 12.85 | -35.3% |
| 7 | + 정기 무료개방일 + 특별행사 | 28.3% | 11.35 | **-42.8%** |

- 1→7행 비용 19.85억 → 11.35억(**-42.8%**, 95% 구간 [-49.2, -36.1]), q80 적중률 0.794
- 정기 무료개방일(5→6행) -7.9% [-12.8, -3.8] — 절감의 60%가 설·추석 연휴가 걸린 6개 원점
- 특별행사(6→7행) -4.1% [-7.8, -0.8] — 절감의 65%가 코리아 그랜드 페스티벌 2개 원점, 블록 8주 구간은 0을 포함
- 명절 4개 원점: 5.93억 → 1.85억(-68.9%)
- 같은 조건 반복 실행 시 최종 예측 차이 0(재현성 확인)
- 해석 주의: 백테스트의 절감률이 미래 운영에서 그대로 달성된다고 보장할 수 없고, 특별행사 효과는 인과가 아니라 "공변량을 추가했을 때의 예측 성능 변화"로만 해석합니다.
